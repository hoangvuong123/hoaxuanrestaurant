# Premium Custom Cursor FX 1.2.0

Advanced WordPress custom cursor plugin built without jQuery, GSAP or Elementor dependencies.

## 16 cursor styles
- Minimal Dot
- Premium Outline
- Soft Glass
- Solid Bubble
- Smart Invert
- Neon Glow
- Bling Bling
- Luxe Gold
- Aurora Glow
- Holographic
- Crystal 3D
- Chrome 3D
- Orbit Rings
- Liquid Blob
- Comet Trail
- Cyber HUD

## Motion / FX
- 3D tilt based on mouse velocity
- Adjustable tilt strength
- Primary and secondary FX colors
- Adjustable glow
- Ambient shimmer / bling / orbit
- Optional trailing effect with adjustable length and opacity
- Comet and Aurora automatically enable trail
- Touch-device detection and viewport breakpoint
- Reduced-motion handling

## 9 click effects
- None
- Press / Shrink
- Pulse
- Ripple
- Double Ripple
- Spark Burst
- Diamond Burst
- Neon Shockwave
- Mini Firework

## Hover labels
Default selector includes `.mtg-card` and `[data-pcc-label]`.

Example:

    <a href="/menu" data-pcc-label="MENU">Speisekarte</a>

## Install / update
1. Deactivate and delete the old Premium Custom Cursor plugin if installed.
2. WordPress Admin -> Plugins -> Add New -> Upload Plugin.
3. Upload `premium-custom-cursor-fx-v1.2.0.zip`.
4. Activate.
5. Go to Settings -> Custom Cursor FX.

Settings use the same `pcc_settings` option key, so compatible settings from the previous build are retained.
